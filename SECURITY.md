# Security policy

Report Dataplicity agent security issues to **support@dataplicity.com** with subject `Security vulnerability`. Do not open a public GitHub issue for unfixed vulnerabilities.

OEM-facing SBOM, update, and supplier information for EU product cybersecurity reviews:

https://docs.dataplicity.com/security/oem-supplier-information

Current agent development (rescue plane + Prelude supervisor), including release SBOMs and the detailed security update policy, lives in the Dataplicity agent release and modern agent source tracks used by current installers.
